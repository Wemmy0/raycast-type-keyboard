# raycast-type-keyboard
A custom Raycast script to type the content of the clipboard
Includes overlay UI of typing status and interruption on key press

## Usage Instructions

1. Install the Apple Command Line tools if you haven't already
```
xcode-select --install
```
2. Make the script executable
```
chmod +x type-clipboard.sh
```
3. Open Raycast Settings, `Script Commands` and add the containing folder as a Script Folder

Then just copy something and run the command.
On the first run you may need to go into System Settings -> Privacy & Security and enable Accessibility for the script
